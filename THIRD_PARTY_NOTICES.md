# UNII attribution

This is an independent Emacs Lisp implementation of the UNII memory design by
Victor Taelin, originally published as OptChat and subsequently named UniiChat.

Upstream specification: https://gist.github.com/VictorTaelin/91837951a5ce5b38f341ec1ba1df6449

The MIT license covers this repository's original implementation and original
documentation. It does not relicense the upstream specification or upstream
prompt text. No upstream specification or prompt text is bundled here.
SlopChat's application-specific prompts and provider adapter are maintained in
SlopChat, outside this package. This package is not an official UNII release.
